📖 About This Database

This database compiles 200+ peer-reviewed publications on hemoglobin-based oxygen carriers (HBOCs), with a special focus on Oxyglobin — the only FDA-approved HBOC for veterinary use.

Coverage: veterinary applications, human clinical trials, adverse effects, oxygen delivery, NO scavenging, microcirculation, HBOC vs blood transfusion, Jehovah's Witnesses, sickle cell, trauma, machine perfusion, organ preservation.
