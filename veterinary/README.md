## About This Database

This database compiles **200+ peer-reviewed publications** on hemoglobin-based oxygen carriers (HBOCs), with a special focus on **Oxyglobin** (hemoglobin glutamer-200, bovine) — the only FDA-approved HBOC for veterinary use.

### Coverage Includes

| Category | Description |
| :--- | :--- |
| 🩸 **Oxyglobin** | Veterinary applications (dogs, cats, horses, exotic species) |
| 🩸 **HBOC-201 / Hemopure** | Human clinical trials and surgical applications |
| 🩸 **Safety & Toxicology** | Adverse effects, vasoconstriction, renal toxicity |
| 🩸 **Mechanisms** | Oxygen delivery, nitric oxide scavenging, microcirculation |
| 🩸 **Comparative Studies** | HBOC vs. blood transfusion vs. colloids |
| 🩸 **Special Populations** | Jehovah's Witnesses, sickle cell crisis, trauma |
| 🩸 **Transplantation** | Normothermic machine perfusion, organ preservation |
